# 💪 תוכנית אימונים - שי

אפליקציית מעקב אימונים אישית (עברית, RTL) — קובץ יחיד שרץ בכל דפדפן, ללא שרת וללא התקנה.
מעקב אחרי תרגילים לפי שבועות (משקל / חזרות), היסטוריית אימונים, אחוזי התקדמות, קישורי YouTube
לכל תרגיל, סנכרון ענן אופציונלי דרך Google Sheets, וגיבוי מקומי לקובץ.

## מבנה הפרויקט

```
workout-app/
├── index.html      ← האפליקציה (HTML + CSS + JS, קובץ יחיד)
├── assets/         ← 18 תמונות התרגילים (WebP)
│   ├── ex01.webp
│   └── ...
├── Code.gs         ← backend הסנכרון ל-Google Apps Script
└── README.md
```

> **חשוב:** התיקייה `assets/` חייבת להישאר לצד `index.html` — התמונות נטענות ממנה בנתיב יחסי.

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן. הנתונים נשמרים אוטומטית ב-`localStorage` של הדפדפן.

## פרסום ל-GitHub Pages

1. להעלות את כל הקבצים (כולל תיקיית `assets/`) לענף הראשי של הריפו.
2. Settings → Pages → Source: הענף הראשי, תיקייה `/root` → Save.
3. הכתובת תהיה `https://<user>.github.io/workout-app/`.

## גיבוי מקומי (מומלץ)

הנתונים מאוחסנים ב-`localStorage`, ולכן **ניקוי הדפדפן או מעבר מכשיר ימחקו אותם**.
כדי לא לאבד מידע:

- **☁️ סנכרן → ⬇️ ייצא קובץ** — יורד קובץ `workout-backup-YYYYMMDD.json` עם כל הנתונים.
- **☁️ סנכרן → ⬆️ ייבא קובץ** — טוען בחזרה קובץ גיבוי (מחליף את הנתונים המקומיים).

## סנכרון ענן בין מכשירים (אופציונלי)

הסנכרון עובד דרך Google Apps Script + Google Sheets, בשיטת JSONP שעוקפת CORS
(עובדת בכל דפדפן ורשת מובייל). ההגדרה חד-פעמית:

1. לפתוח **Google Sheet** חדש (ישמש כמאגר הנתונים).
2. `Extensions → Apps Script`, למחוק את קוד ברירת המחדל ולהדביק את כל תוכן **`Code.gs`**.
3. לשמור, ואז `Deploy → New deployment → Web app`:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. לאשר הרשאות ולהעתיק את כתובת ה-`/exec`.
5. באפליקציה: כפתור **☁️ סנכרן** → להדביק את הכתובת → **⬆️ שמור לענן** / **⬇️ טען מהענן**.

> בכל עדכון של `Code.gs` צריך `Deploy → Manage deployments → עריכה → Version: New version`,
> אחרת האפליקציה עדיין תריץ את הגרסה הישנה.

### איך זה עובד (למי שסקרן)

בשמירה, מצב האימונים מסודר כ-JSON, מפוצל לחתיכות של 1500 תווים ונשלח אחת-אחת
(`?action=chunk&i=&n=&d=`). השרת צובר את החתיכות, מאמת ומאחסן את התוצאה בתא `A1`
בגיליון. בטעינה, השרת מחזיר את האובייקט כ-JSONP והאפליקציה ממזגת אותו למצב המקומי.

## מה שופר בגרסה הזו

- **משקל האפליקציה**: 18 תמונות שהיו מוטמעות כ-base64 בתוך ה-HTML הוצאו לקבצי WebP חיצוניים
  והוקטנו. ה-`index.html` ירד מ-**2.28MB ל-~81KB** (טעינה ראשונית מהירה בהרבה), וסך המשקל
  של האפליקציה ירד ל-~0.9MB.
- **`Code.gs`** נוסף לריפו (קודם ההוראות הפנו אליו אך הוא לא היה קיים).
- **ייצוא/ייבוא JSON** נוספו כגיבוי מקומי בטוח ל-`localStorage`.
- **README** מלא עם הוראות הרצה, פרסום, גיבוי וסנכרון.
